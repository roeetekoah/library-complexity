# Sources and release scope

This repository curates Roee Tekoah's Computational Genomics Exercise 2 work on library complexity. Original coursework files are preserved separately; this release does not modify those sources.

| Release material | Origin / treatment |
|---|---|
| `analysis/q2a.py`, `q2b.py`, `q3a.py`, `q3b.py`, `q3d.py` | Copied unchanged from the original exercise analysis scripts. |
| `docs/report/` | Original `report/report.pdf`, `report.tex`, and referenced standalone figure PDFs, copied unchanged. This is the main 14-page report, not `report_full.pdf` or a new scientific revision. |
| `docs/primers/` | Original self-written subsampling and statistical-testing primers, with accompanying TeX and subsampling figure PDFs. The student identifier was removed from release PDFs and TeX; PDF metadata was cleared. |
| `figures/` | PNG renders of three original result PDFs: saturation, histogram model-fit, and length-distribution comparison. No values, labels, or curve geometry were changed. |
| `tools/demo.py` | Packaging addition: deterministic synthetic inputs and a subprocess runner for the original scripts. Synthetic output is excluded from version control. |
| README, methods/running guides, dependency file | Release navigation and accurate, bounded interpretation of existing work. |

Supplied raw sequencing CSVs, the exercise handout, lecture material, unrelated backups, generated TeX caches, and submission archives are excluded. The source report retains brief references and question excerpts to explain its coursework context; the complete assignment handout is not distributed.

No grade is asserted. No open-source license is selected in this packaging pass. Inclusion here does not establish redistribution rights for excluded course datasets or materials.
